# Portfolio listing (draft — adjust after Windows testing)

**Title:** LibraryDesk — C# Library Management Desktop App

**One-line summary:** A lightweight Windows desktop library manager with a clean catalog, search, persistent book records, and issue/return tracking.

**Role:** Independent portfolio project (modernized from my earlier student project).

**Problem:** The original library app was difficult to navigate and lost all catalog data when closed.

**Solution:** Refreshed the WinForms interface, added local XML persistence, searchable book lists, borrower names, loan due dates, overdue status, and simple admin catalog management.

**Technology:** C#, Windows Forms, .NET Framework 4.7.2, XML.

**Suggested screenshots:** Home dashboard, book catalog, issue/return workflow. Capture these on Windows from the running application.

**Scope note:** Offline desktop demo; not a commercial library system, not a deployed web app, and not a real client commission.
